# Data Cleaning Pipeline

Here we describe the data cleaning pipeline, for which the scripts can be found in `scripts/data_cleaning`.

| Num | Script                      | Description                                                                               | Input File(s)                                                                                                          | Output File                                       |
| -----| -----------------------------| -------------------------------------------------------------------------------------------| ------------------------------------------------------------------------------------------------------------------------| ---------------------------------------------------|
| 1.  | combine_datasets.py         | Combining raw Hardcover and ISFDB datasets.                                               | 'hardcover_bookdetails.csv', 'isfdb_novels_06-06_with-null-isbn.csv'                                                   | isfdb-hardcover-combined.csv                      |
| 2.  | match_awards_dataset.py     | Label nominees for Hugo and Locus awards, and identify nominees missing from the dataset. | 'hugo_nominees.csv', 'locus_nominees.csv', isfdb-hardcover-combined.csv                                                | 'isfdb-hardcover-awards.csv', 'missing_books.csv' |
| 3.  | get_missing_novels.py       | Query Hardcover API to get info on missing nominees.                                      | 'missing_books.csv'                                                                                                    | "missing_book_details.csv"                        |
| 4.  | format_missing_finalists.py | Combine missing finalists with original database.                                         | "missing_books.csv", "missing_book_details.csv", 'hugo_nominees.csv', 'locus_nominees.csv', isfdb-hardcover-awards.csv | "final_book_dataset.csv"                          |
| 5.  | data_cleaning.py            | ..                                                                                        | ..                                                                                                                     | ..                                                |
